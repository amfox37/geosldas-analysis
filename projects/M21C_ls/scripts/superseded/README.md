# Superseded scripts

Retained for the record; not part of the analysis described in
`docs/regional_rzmc_transition_diagnostic.md`.

- `run_regional_rzmc_changepoints.py` — blind PELT changepoint detection on the
  regional RZMC series, together with the check that PELT accepts identical
  break dates on standardized and native-unit seasonally adjusted series. The
  regional analysis now uses observing-system period means directly, so this is
  no longer run. Its results are summarized in the diagnostic report.
