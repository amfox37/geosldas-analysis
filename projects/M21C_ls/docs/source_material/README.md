# Source Material

Files in this directory are historical/source documents used during the manuscript rebuild.

They are **not authoritative working manuscript text**.

For current scientific conclusions, use:

`../notes/current_scientific_state.md`

For manuscript structure and current working text, use:

`../manuscript/manuscript.md`

`draft_052426.pdf` is the May 24, 2026 manuscript draft. It may be consulted for earlier prose, references, methods descriptions, dataset descriptions, and context.

Where the May draft conflicts with:

- `../notes/current_scientific_state.md`
- subsequent accepted analysis reports
- the current figure set
- later documented manuscript decisions

the newer material takes precedence.

Do not copy old manuscript text into the rebuilt manuscript merely because it exists in this PDF. Reuse material selectively and only where it remains scientifically and structurally appropriate.
